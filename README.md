# Personality Assessment Simulator — Streamlit

A 200-question personality assessment simulator inspired by the style of repeated, indirect personality questioning. It is **not an official ISSB test** and should not be described as reproducing ISSB's proprietary/validated psychological assessment.

## Features

- 200 original multiple-choice personality questions.
- Five-point response scale: Strongly Agree → Strongly Disagree.
- 10 scored dimensions:
  - Self-confidence
  - Leadership
  - Teamwork
  - Emotional stability
  - Integrity
  - Responsibility
  - Adaptability
  - Communication
  - Initiative
  - Discipline
- Reverse-scored questions to reduce simplistic answer patterns.
- Paired questions that revisit the same underlying trait from another angle.
- Explicit contradiction detector showing:
  - contradiction pair ID
  - both question IDs
  - both exact question texts
  - both selected answers
  - affected personality dimension
- ML-assisted assessment using a Random Forest model.
- Final score combines a transparent rubric with the model estimate.
- CSV download of all answers.
- Restart and resume navigation using Streamlit session state.

## Important validity note

The ML model is trained on **synthetic response patterns generated by the app**. This gives the project a real model-based inference component, but it does **not** make the assessment scientifically validated. A serious production version would require a properly designed item bank, psychometric validation, a representative labeled dataset, reliability testing, bias analysis, and appropriate professional oversight.

## Local setup

### 1. Create a virtual environment

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Install libraries

```bash
pip install -r requirements.txt
```

### 3. Run

```bash
streamlit run app.py
```

## Deployment on Streamlit Community Cloud

2. Open Streamlit Community Cloud.
3. Select the GitHub repository.
4. Set the main file to `app.py`.
5. Deploy.

## How contradiction detection works

Each linked pair targets the same personality dimension. Answers are converted to a 1–5 latent direction. Reverse-scored statements are flipped so that a higher normalized number always means stronger endorsement of the trait. When the two linked responses differ by at least the configured threshold, the pair is flagged.

Example:

```text
Q003: I hesitate to express an idea because I fear being judged. → Strongly Agree
Q103: I am comfortable presenting my view even when others disagree with me. → Strongly Agree
```

The report will identify the pair and show both questions and answers.

## Suggested production upgrades

- Move the question bank to JSON/CSV/database instead of hard-coding it.
- Add question randomization with controlled trait balancing.
- Add response-time analysis without treating speed as a personality diagnosis.
- Add social desirability / impression-management scales.
- Add a calibration dataset and train the ML model on real, consented, professionally scored data.
- Add reliability metrics such as Cronbach's alpha/omega and test–retest checks.
- Add an admin page for versioning question banks.
- Add a report PDF and candidate history database.

## Timed practice mode and multiple attempts

The simulator now includes a live countdown timer. The default practice preset is **20 minutes for 200 MCQs**, with selectable practice limits of 10, 15, 20, 25, 30, or 40 minutes. The timing is a training simulation and is not presented as an official ISSB timing rule because the official ISSB site does not publish a specific OPI timing in the material used by this project.

When the timer reaches zero, the current answers are automatically submitted and analyzed. Unanswered questions remain marked as `Not answered` in the CSV export.

The question bank has been expanded to **400 questions arranged into 200 linked pairs**. Every attempt selects 10 complete pairs per personality dimension, producing a balanced 200-question test while allowing subsequent attempts to use different MCQs. The app also changes the order on every attempt.

A second or later attempt therefore changes both:

1. The actual MCQs selected from the larger pool.
2. The order in which those MCQs appear.

The contradiction engine works on the selected paired questions, so linked consistency checks remain available even when the question set changes between attempts.
